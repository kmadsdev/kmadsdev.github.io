Designed in boxes.

The kmadsdev portfolio isn't a stack of cards floating on gradients — it's a blueprint of modules. Vertical guides, hairline borders, indexed labels, diagonal stripes, layered glows. This page documents the tokens and components that build those modules, with live demos rendered from the same CSS the production prototype ships.

Rubik + JetBrains Mono Single accent · #ff014f 12-column module grid 3 line-weight tokens Zero JS layout

00 The thesis

Personal portfolios drift toward shapes — rounded cards floating on gradients, parallax illustrations, hero collages. Recruiters scan them as fluff. So the brand picks the opposite vocabulary: schematics.

Three principles

  • Every section is a module. Bordered, labeled, indexed (00 / KMADSDEV through -1 / THE END). The eye reads it like a plan view, not a feed.
  • Borders carry the design, not shadows. Three line-weight tokens (--module-line-soft, --module-line, --module-line-strong) do the entire compositional job.
  • Cells are not cards. Cards float; cells belong to a frame. Removing border-radius and uniting them with a 12-col grid turns each section into a single object.

This is a fork of agentic/.design-system/modular-design.html, recolored from green to #ff014f and revoiced from "agent speed" to "50+ projects since 2018, still no idea what I'm doing."

05 Modular cells

Cells are the building blocks of any module body. Hover for the glow.

STEP 01

Build it

Open the editor. Write the function. Make it work first.

STEP 02

Ship it

Push to main. Let CI run. Ignore the warnings just this once.

STEP 03

Document it

Write what it does. What broke. Why the fix worked.

Cells share the same recipe: hairline grid background (var(--module-cell) = 58px), soft right + bottom borders only, no radius. The last cell in a row drops border-right. Hover triggers a radial pink glow tinted with --color-accent-glow.

08 Do & don't

Do

  • Render the globe massively in the hero. It IS the brand.
  • Index every section: 00 / KMADSDEV, 01 / WHO, …, -1 / THE END.
  • Use one accent — #ff014f — per page region.
  • Mono for eyebrows, tags, badges, code, file paths.
  • Sentence-case headlines with periods. The number earns the joke.
  • Cells in a module = radius 0. Cards float; cells belong.

Don't

  • Shrink the globe to a navbar icon.
  • Skip section indices. They're the rhythm.
  • Add a second accent (blue, green) — even for a project's logo color.
  • Use mono for body or headlines.
  • Title-Case Headlines. Or marketing !.
  • Apply border-radius to cells inside a module.
  • Use emoji in shipped copy. Allowed only as temporary icon placeholders.
