Designed in boxes.

The kmadsdev portfolio isn't a stack of sections — it's a blueprint of modules. Vertical guides, hairline borders, indexed labels, diagonal stripes, layered glows, variable-span cells. This page documents every strategy used to compose those modules, with live demos rendered from the same CSS the production prototype ships.

12-column module grid 3 line-weight tokens Indexed sections Single accent · #ff014f Zero JS layout

00 The thesis

Personal portfolios drift toward shapes — rounded cards floating on gradients, parallax illustrations, hero collages. Recruiters scan those as fluff. So the brand picks the opposite vocabulary: schematics.

Three principles

  • Every section is a module. Bordered, labeled, indexed. The eye reads "02 / WORK" the way it reads a wiring diagram.
  • Borders carry the design, not shadows. Three line-weight tokens (soft, base, strong) do the entire compositional job. No drop-shadows in the layout.
  • Cells are not cards. Cards float; cells belong to a frame. Removing border-radius and uniting them with a 12-col grid turns each section into a single object.

This page exists because reproducing those rules from memory is brittle. The next contributor — or future Kaique — needs the strategies, not just the tokens.

The system is forked from agentic/.design-system/modular-design.html. Same skeleton. Different brand body: #ff014f instead of #33b474, Rubik instead of Inter, "kmadsdev" instead of "Agentic Template".

02 Modular tokens

Six tokens carry the entire modular system. Borders use only three weights so the eye can rank importance.

TokenValueUse
--module-max1180pxOuter width of every module
--module-line#262629Base. Section borders, label dividers, grid guides
--module-line-soft#1c1c1fSoft. Cell borders inside a module — quieter than the frame
--module-line-strong#3a3a40Strong. Hero stage frame, terminal cards — earns more attention
--module-cell58pxInner grid cell size for cell backgrounds (the faint dotwork)
--module-striperepeating-linear-gradient(135deg, …)Diagonal closer band

Three line weights map to three depth levels: frame > cell > sub-cell. Pick one per layer; never mix two on the same edge.

03 The 12-column grid

Every module body sits on a 12-col grid. The grid is visible — vertical hairlines paint themselves into the background of .module via a linear-gradient. Cells then snap to span N.

styles/prototype.css background-as-grid 
.module {
    border-right: 1px solid var(--module-line);
    border-left:  1px solid var(--module-line);
    background:
        linear-gradient(to right, var(--module-line-soft) 1px, transparent 1px),
        var(--color-background);
    background-size: calc(100% / 12) 100%, auto;
}

04 Section labels — the index ribbon

Every section gets an index. The portfolio reads as seven indexed pieces + a closing footer. The numbering is intentional: 00 is the hero (the brand), positive numbers are content, -1 is the closer (out of band, explicitly).

00 / KMADSDEV
01 / WHO
02 / WORK

Sub-indices like 02.A, 03.E are used for sub-modules inside a parent module (Education inside Work, Agents inside Stack). They read as "section 02's appendix A" and keep the rhythm without inventing new top-level sections.

05 Two-column headers

Every .module__header is a 12-col grid: headline takes 8 cols on the left, lede takes 4 cols on the right, bottom-aligned. This asymmetry is what gives the modules their "diagram" feeling — a label paired with a margin note.

02/ WORK

Where I worked. Where I studied.

Six roles. Eight years. The ones that paid, the ones that didn't, the ones that taught.

07 Border-work

Borders are not decoration — they are the layout. Three rules govern every line on every page.

  • Frame > Cell > Sub-cell. If a layer wraps another, the outer line must be heavier than (or equal to) the inner one.
  • Last in row drops border-right. The frame already provides that line.
  • Last row drops border-bottom. The next module's border-top handles the seam.

08 Dividers & diagonal stripes

The diagonal-stripe band closes a module. Same pattern across every section. Used in three places only: module footer, hero footer, and any cell intentionally rendered "empty" to mark negative space.

Spec: repeating-linear-gradient(135deg, transparent 0 18px, rgba(255,255,255,0.06) 18px 19px, transparent 19px 38px). The 18 px stripe / 19 px gap rhythm is identical to agentic/ — preserved on purpose so workspace projects share visual DNA.

10 Hero stage — the globe frame

The hero is the only module that uses --module-line-strong for its outer frame. The globe lives inside a stage cell, not floating freely. Corner markers (top-left + bottom-right) reinforce the "blueprint" gesture and frame the globe as a figure (FIG · 00.A).

Layers

  • Outer frame — --module-line-strong, the heaviest line on the page. Earns the heaviest weight because the hero is the only module without a continuation.
  • Asymmetric grid — 1.05fr / 1fr. Copy slightly larger than stage to balance the globe's visual weight.
  • Stage — its own grid background (faint dotwork, 58px), corner markers in --color-accent, radial pink glow at center.
  • Globe — outer ring (globe-text.svg) rotates 20s linear infinite; inner globe (globe.svg) is still. Both are SVG, no rasterization. prefers-reduced-motion disables the rotation.
  • Figure label — FIG · 00.A — kmadsdev mark in mono, bottom-left of the stage. Reads like an academic figure caption.

12 Do & don't

Do

  • Index every new section. Never ship an unlabeled module.
  • Reuse existing border tokens. Three weights are enough.
  • Drop border-right on last cell of a row, border-bottom on last row.
  • Use mono only for technical micro-copy (indices, code, tags).
  • Keep the globe massive in the hero. It IS the brand.
  • Close every module with the diagonal stripe.

Don't

  • Add a fourth border weight. Pick one of the three.
  • Round cells inside a module. Cells belong; cards float.
  • Use mono for body or headlines.
  • Add a second accent (blue, green, purple) — even for a project's logo color.
  • Skip the section index on a sub-module. Use sub-index notation: 02.A, 03.E.
  • Drop the diagonal closer because "this section feels different". It doesn't.
